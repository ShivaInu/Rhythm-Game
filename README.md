# リポジトリ概要
音ゲーの方の応募作品のソースコードをこちらにアップロードいたしました。コードの量が割と多いため、フォルダー構造を説明し最も重要なファイルを指摘します。
## リポジトリ構造
### Core
ゲームの流れやBGMを制御するスクリプトのサブディレクトリです。
#### 目立つファイル
= **AudioManager.cs** - ゲーム内のBGMと効果音、音楽との同期を担当する
- **GameManager.cs** - ゲーム開始で行われる処理を担当し、一時停止メニューも担当する
### Data
譜面データ、プレイヤー設定、ランキングサーバーとの連携を担当するスクリプトが入っているサブディレクトリです。
#### 目立つファイル
- **RankingManager** - オンライン機能を担当する
### Gameplay
ゲームで使われているオブジェクトやシステムのサブディレクトリです。
#### 目立つファイル
- **EditorManager.cs** - 譜面エディターのほとんどの機能を担当する
- **JudgeManager.cs** - ノート判定システム
- **NoteSpawner.cs** - ノートの生成システム
- **Note.cs** - ノートを定義するクラス
### UI
UIを制御するスクリプトのサブディレクトリです。
#### 目立つファイル
- **SongSelectController.cs** - 選曲画面の制御スクリプト



ファイルのコメントでも軽い紹介が書いてあります。
